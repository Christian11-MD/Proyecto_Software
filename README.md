
# Sistema de Gestión de Citas Médicas - UNA Puno

## Descripción
Proyecto académico para gestionar las citas médicas
del Servicio Médico Primario de la UNA Puno.

## Funcionalidad individual
RF02 - Consultar estado de cita.

Permite que el estudiante ingrese el código de su cita
y consulte su estado: pendiente, confirmada o cancelada.

## Tecnologías
- PHP 8.2
- HTML5
- CSS3
- Git y GitHub
